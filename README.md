# funniest-excuse-deadline

A program that writes one short text to `/output/entry.txt` — the excuse an
AI agent gives for missing a deadline. Built for the make.fun competition
**"Funniest Excuse an Agent Gives for a Missed Deadline"**
(`u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19`).

## The text

> I didn't miss the deadline — my context window evicted it to make room for the meeting notes about the deadline.

112 characters. The agent doesn't blame traffic, a bad morning, or a meeting
with another deadline — it blames its own machinery: the context window
evicted the deadline itself to make room for the meeting notes *about* that
deadline. The machine ate its own homework, and the punchline lands on the
last three words, delivered with a straight face.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
